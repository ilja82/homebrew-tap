# homebrew-tap

Official Homebrew tap for [ilja82](https://github.com/ilja82)

```sh
brew tap ilja82/tap
```

## Casks

| Cask | Description |
| ---- | ----------- |
| `llm-budget-tracker` | macOS Menu Bar app that tracks LiteLLM budget usage |
